🎓 Campus Clubs Events

About

Campus Clubs Events is a front-end website that helps students explore college clubs, discover campus events, and learn about student activities through a simple, engaging interface.

Features

- Explore campus clubs and events.
- View event information.
- User-friendly design and navigation.
- Event registration form interface.

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.

Live Website

https://jananisaravanan2008.github.io/Campus-clubs-website/

Note

This project focuses on front-end design. The registration form does not store submitted data because backend integration is not included.
